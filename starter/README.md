# Starter PosterKu

Folder ini adalah **titik mulai peserta kelas**. Belum ada kode di sini; kodenya
akan dibuat oleh agen AI (Antigravity atau Codex) mengikuti prompt di kelas.

## Isi

| File/folder | Fungsi |
|---|---|
| `AGENTS.md` | cetak biru + aturan kerja untuk agen AI (jangan dihapus) |
| `.agents/` | aturan dan pintasan `/jalankan`, `/cek-kualitas`, `/simpan`, `/batalkan`, `/publish` untuk Antigravity |
| `kelas/` | materi, aturan pakai, dan prompt per sesi |

> Folder `.agents` diawali titik, jadi bisa tersembunyi di Finder/Explorer.
> Di macOS tekan `Cmd + Shift + .` untuk menampilkannya.

## Mulai

1. Salin folder `starter` ini ke tempat yang mudah dicari, lalu beri nama
   `posterku`.
2. Buka folder itu di **Antigravity** (File → Open Folder) atau di **Codex**.
3. Baca `kelas/ATURAN-PAKAI.md` dan `kelas/CARA-PAKAI-AGENTS.md`.
4. Buka `kelas/prompts/01-proyek-awal.md`, lalu salin prompt-nya ke agen.
